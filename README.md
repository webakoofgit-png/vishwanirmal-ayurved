# Vishwanirmal Ayurved

Public website exported from the restored WordPress site. Pages and posts are stored as HTML with clean directory URLs. Linked stylesheets, scripts, images, and fonts are included where available.

Serve this directory with a static web server. For example, run `python -m http.server 8000` and open `http://localhost:8000/`.

The static site requires a WordPress backend for search and form submissions. Some unavailable images use placeholders.
